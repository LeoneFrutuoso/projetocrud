# projetocrud # CRUD de Tarefas (Simples)

Projeto crud organizaçao de tarefas trabalha com o objetivo de criar um sistema básico de cadastro, leitura, edição e exclusão (CRUD) usando HTML, CSS e JavaScript puro, salvando os dados no navegador (LocalStorage).

## 🚀 Funcionalidades

* **Cadastrar:** Adiciona uma nova pessoa/tarefa com dados como nome, idade, disponibilidade, horário, restrições e status de conclusão.
* **Listar:** Mostra todas as pessoas cadastradas em formato de cards na tela.
* **Pesquisar:** Busca pelo nome para carregar os dados de alguém específico de volta no formulário.
* **Editar (Salvar):** Permite alterar os dados de um cadastro existente após fazer a busca.
* **Excluir:** Remove o cadastro do sistema.
* **Persistência:** Os dados ficam salvos no `localStorage` do navegador, então não somem se você atualizar a página.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura da página e formulários.
* **CSS3:** Estilização básica e organização dos elementos (Flexbox).
* **JavaScript (Vanilla):** Lógica do CRUD, manipulação do DOM e integração com o LocalStorage.

## ⚙️ Como executar o projeto

1. Baixe ou clone este repositório.
2. Certifique-se de que os arquivos estão na mesma pasta:
   * `index.html`
   * `style.css`
   * `script.js`
3. Abra o arquivo **index.html** em qualquer navegador web (Brave, Chrome, Firefox, etc.).
